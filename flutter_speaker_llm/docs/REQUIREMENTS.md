# 需求文档 — flutter_speaker_llm

版本：0.1 ｜ 状态：开发中（代码已成型，待编译验证）

## 1. 背景与目标

为望远镜/天文摄影类 App 提供**离线语音控制**能力，并做成**可复用库**，方便集成到
其他 App。用户对着麦克风说话即可触发设备指令，全程在设备本地完成（不联网、不依赖
云服务），支持中/英/日/西等多语种。

**核心目标**
- G1 语音免触控操作设备（唤醒 → 说指令 → 执行）。
- G2 全本地离线、隐私安全。
- G3 库化、指令完全由集成方配置。
- G4 App 安装包小，大模型首启按需下载（可走自有 CDN）。
- G5 跨平台：Android / iOS / macOS / Windows。

## 2. 范围

**In scope**：唤醒词检测、离线 ASR、本地 LLM 意图识别与参数抽取、指令派发框架、
语音反馈、模型下载与管理、配置化指令、示例 App。

**Out of scope**（由集成方实现）：具体指令的业务逻辑（对极轴/拍摄等的实际控制）、
设备连接协议、账户体系、UI 主题。

## 3. 角色

- **集成方开发者**：在自己的 App 里引入本库，配置指令与模型源，注入 handler。
- **终端用户**：对着 App 说话完成操作。

## 4. 术语

| 术语 | 含义 |
|------|------|
| 唤醒词 KWS | Keyword Spotting，检测固定唤醒短语（默认 "hi synlink"） |
| VAD | 语音活动检测，判断说话开始/结束（断点） |
| ASR | 自动语音识别，语音转文字（Whisper 多语种） |
| 意图/指令 | 用户话语映射到的工具（tool），可带参数 |
| 门面 | `SynlinkEngine`，集成方唯一入口 |

## 5. 功能需求（FR）

### FR1 唤醒监听
- 打开后**常驻监听麦克风**，检测到唤醒词 "hi synlink" 才进入录音。
- 唤醒词可配置（`SynlinkConfig.wakeWord`），灵敏度可配置（`wakeWordThreshold`）。
- 验收：静音/背景说话不误触发；说出唤醒词后进入采集状态。

### FR2 语音识别（多语种）
- 唤醒后开始录音，**用户停止说话自动结束**（VAD 断点），将这段语音转成文字。
- 支持中/英/日/西等 ~99 种语言（Whisper），可自动检测语言，也可强制语言。
- 单句封顶时长可配（默认 30s）。
- 验收：对四种语言各说一句命令，能得到对应文字。

### FR3 语义/意图识别
- 把转写文字交给本地 LLM（Qwen2.5‑0.5B），识别为**唯一一个指令**并抽取参数。
- 多语言输入都能正确映射（如中文"对极轴"、英文"goto M31"、西语"enfoca"）。
- 无法匹配时返回"未识别"。
- 验收：示例指令在四语种下命中率达到可用水平；"goto M31" 能抽出 `target=M31`。

### FR4 指令匹配与参数抽取
- 指令以**工具名**标识；参数按工具的 JSON‑schema 抽取。
- 验收：`Command.name` 正确、`Command.params` 含期望参数。

### FR5 指令执行
- 通过集成方注入的 handler 执行；库不含任何业务逻辑。
- 验收：命中指令时对应 handler 被调用并拿到参数。

### FR6 语音反馈（TTS）
- **指令未识别/出错时用语音提示**用户（如"没听懂指令，请再说一次"）。
- 反馈语言跟随用户说话语种；文案可被集成方覆盖；可选成功确认播报。
- 默认系统 TTS（零下载）；可选 sherpa 离线 TTS。
- 验收：说一句无关的话 → 用对应语种播报未识别提示。

### FR7 模型下载与管理
- App 安装小，**首启下载** LLM + 语音模型；带进度、断点续传、失败指数退避重试、
  SHA‑256 校验。
- **下载 URL 全部可配置**（默认官方源；可一键切自有 CDN）。
- 按平台选模型格式：移动/Web 用 `.task`，桌面用 `.litertlm`。
- 空闲时卸载大模型释放内存。
- 验收：首启能下载完成并落盘；断网重试可续传；二次启动直接就绪。

### FR8 配置化指令
- 集成方通过 `SynlinkConfig.commands`（`CommandDefinition`：名字+描述+参数 schema+handler）
  定义**自己的整套指令**；也可运行时 `addTool`。
- 验收：不改库代码即可新增/替换指令并生效。

### FR9 库化
- 以 Flutter 包形式提供，干净的门面 API；附 example 演示集成。
- 验收：example 仅依赖本库即可跑通完整链路。

## 7. 多语言要求
- ASR 与 LLM 均多语种；至少覆盖中、英、日、西，并尽量覆盖更多世界语种。
- 语音反馈内置 zh/en/ja/es 默认文案，其他语种回退英文，可覆盖。

## 8. 非功能需求（NFR）

| 编号 | 需求 |
|------|------|
| NFR1 性能/省电 | 常听场景下：便宜的 VAD 门控昂贵的 KWS 解码；重模型懒加载+空闲卸载；推理在后台 isolate 不卡 UI；int8 量化 + 16k 原生采样；`PowerMode` 三档可调。 |
| NFR2 包体积 | 安装包尽量小；大模型不入包、按需下载。 |
| NFR3 离线/隐私 | 全本地，无音频/文本上云。 |
| NFR4 跨平台 | Android/iOS/macOS/Windows 一致可用。 |
| NFR5 内存 | 单句封顶时长限制内存；空闲卸载；移动端可运行 0.5B 级模型。 |
| NFR6 健壮性 | 麦克风占用/权限撤销/设备热插拔/来电中断可恢复；下载失败可重试。 |
| NFR7 可维护/可扩展 | 指令、LLM 后端、TTS 引擎均可替换/扩展。 |

| 能力 | Android | iOS | macOS | Windows |
|------|:--:|:--:|:--:|:--:|

## 10. 用户流程

1. 首次打开 → 引导下载模型（进度条）。
2. 授予麦克风权限 → 开始常听。
3. 说"hi synlink" → 进入采集。
4. 说指令（任意支持语种）→ 转写 → 意图识别。
5. 命中 → 执行 handler（可选成功播报）；未命中 → 语音提示重试。
6. 回到常听。后台自动暂停，回前台恢复。

## 11. 验收标准（汇总）
- 四语种各跑通"唤醒→指令→执行"全链路。
- `goto M31` 正确抽参。
- 无关话语触发未识别语音提示。
- 断网后重试可续传；二次启动免下载直接可用。
- 四端均可构建运行；后台暂停/恢复正常；TTS 与录音不冲突。

## 12. 约束与假设
- 唤醒词为英文短语（KWS 英文模型）；命令内容多语种由 Whisper 处理。
- 需要集成方提供模型下载源（默认官方，建议自有 CDN）。
- 设备需具备运行 0.5B 量化 LLM 的算力/内存（中端及以上）。
