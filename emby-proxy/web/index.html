添加站点

就是你原来在播放器里填的服务器地址。
自动用最快的一条，某条坏了自动换，播放不中断。
推荐，所有播放器都支持。用 nginx 做 HTTPS 时，在下面「高级选项 → 客户端访问地址」填 https://域名:对外端口。
入口/
多个站点共用一个端口，播放器填 入口地址/hk。
这个域名要解析到本机。
经过本机：线路更好、拖动更稳，但用本机流量。播放器直连：只代理浏览，视频直接从服务器拉，省流量。
高级选项（一般不用改）
防扫描、防白嫖：地址后面要加 /密钥 才能用（卡片上的地址会自动带上）。
前面有 nginx / CDN 时填写，多台服务器时必填。
服务器连不上或很慢时试试切换。
多台服务器时，服务器封了某台的 IP 就填它，那台的用户改走别的节点。
播放时自动学习，一般不用填。
可用 {public_base}（客户端地址）、{public_origin}、{client_ip}。
服务器要求把某个路径转到别处时用，{arg.名称} 取请求参数。
