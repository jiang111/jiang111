添加站点

填你在客户端里原本填写的服务器地址（含端口）。如果服务器有路径（如 https://a.com/xxx）也一起填。
兼容性最好（所有客户端都支持）。直接对外：防火墙放行该端口。前面有 nginx 做 HTTPS：在「高级选项 → 客户端访问地址」填 https://域名:对外端口，到「设置」里生成 nginx 配置。
入口/
多个站点共用一个入口端口/域名，客户端地址填 入口地址/hk。Infuse、SenPlayer、Forward、VidHub、Emby 官方等支持带路径的地址。
把该域名解析到本机并反代到入口端口（需保留 Host 头）。
上游如果做了推流分离（播放时 302 跳到别的推流域名）：「中转」会由本机直接跟随播放跳转（客户端拿到的是 206，兼容 Exo 等播放器的 Range/拖动），推流也经本机转发（改善线路，但消耗本机流量）；「直连」只代理 API，视频流让客户端直接连推流服务器（省流量）。
高级选项
播放时自动学习，一般不用手动填。只有列表里的域名才允许经本机中转。
前面套了 CDN/反代且没传 X-Forwarded-* 头时才需要填写。
值里可用占位符：{public_base} 客户端访问地址（含路径前缀）、{public_origin} 不含路径、{client_ip} 客户端 IP。
服务器自带推流路径时使用：匹配该路径的请求（路径和参数原样）转发到目标。{arg.名称} 取请求参数，只允许字母数字和 -。
